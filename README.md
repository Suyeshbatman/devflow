# DevFlow

An all-in-one developer platform: analytics, a tools marketplace, AI assistance,
a learning hub, and real-time notifications. Built as a set of microservices.

## Tech stack
- Backend: Java 21, Spring Boot
- Databases: PostgreSQL, Redis
- Messaging: Kafka
- Frontend: React
- Infrastructure: Docker

## Project structure
- `services/` — backend microservices (one folder per service)
- `frontend/` — React web app
- `infra/` — Docker and deployment configuration
